# Budget Buddy 💰

Budget Buddy is a Python application designed to help users track expenses, manage budgets, and send email notifications for financial updates.

## Features

- Email notifications via Gmail SMTP.
- Environment-based security for credentials.

## Setup Instructions

### 1. Clone the Repository

```bash
git clone [https://github.com/your-username/budget-buddy.git](https://github.com/your-username/budget-buddy.git)
cd budget-buddy
```
