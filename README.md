# Budget Buddy 💰

Budget Buddy is a Python-based web application designed to help users track expenses, manage personal budgets, and send email notifications for key financial updates.

---

## 🌟 Features

- **Expense & Budget Tracking:** Keep track of income and daily expenditures easily.
- **Automated Email Alerts:** Receive notifications and balance updates via Gmail SMTP.
- **Secure Configuration:** Environment-based key management to keep credentials and API keys safe.

---
